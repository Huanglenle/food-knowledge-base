## 两个「官方公开」的重量级配方

市面上绝大多数品牌配方属商业机密，本项目收录了公开渠道确认过的官方配比，可作为复刻锚点：

**霸王茶姬**（2024 年公开成分表）：茶汤 **66%** + 优质牛乳 **19%** + 冰勃朗基底乳 **8%** + 风味糖浆 **7%**
> 关键在基底乳只占 8%——很多人复刻失败正是猛加奶基底，变成甜腻香精味。

**茉酸奶**（国内现制酸奶领域首家公开配方）：牛油果冰沙 **58%** + 醇臻厚乳/牛乳 **19%** + 有机酸奶 **17%** + 果肉盖顶 **6%**
> 结构逻辑和奶茶相反：果肉冰沙为主、酸奶只占约 1/5。酸奶放太多，打出来是稀酸奶而非奶昔。

## 功能特性

- **六大分类频道**：频道页 Tab 切换（常识科普 / 配方分组 / 工具箱），分组页折叠列表
- **全文搜索**：配方、原料品牌、常识科普、工具表四类内容统一检索
- **配料品牌推荐**：每条配料自动关联网友口碑推荐品牌（「荐」字标注），如冰勃朗→圣吗哪、茉莉雪芽→茶半春
- **来源可信度标注**：官方公开 / 门店 SOP（网传）/ 网络复刻，三级分明
- **常识科普**：鲜牛奶与牛乳的区别、基底乳是什么、基底酒怎么选、江西锅气怎么炒、客家人的「酿」……
- **通用配比工具箱**：万能奶液公式、茶汤冲泡参数表、糖浆换算表、奶盖与小料
- **云服务**（可选）：微信授权 / 手机号登录、云端收藏同步、AI 配方问答（登录后可用）

## 内容原则

- 轻油、轻盐、轻糖，不做油炸；每道菜谱均带减油减盐减糖的具体技巧
- 品牌精确配方属商业机密，本项目内容整理自公开渠道（官方公开信息、网络流传配方、网友实测复刻），仅供家庭 DIY 参考
- 原料品牌推荐为公开口碑汇总，与任何品牌无利益关联

## 内容如何扩展（配置驱动）

知识库为纯配置驱动，加内容只改 `<script>` 顶部的数据区，无需改动视图逻辑：

1. **加配方** → `DATA.push({ cat, group, name, type, tea, items, tips, level, src })`，新分组名自动出现
2. **开新分类** → `CATEGORIES` 对应项 `ready: true` + 补 `groupLabel`
3. **加科普** → `PRIMERS[分类id].push({ q, a })`
4. **加原料品牌** → `BRANDS_DATA` 对应面板 `rows.push(...)`
5. **配料自动带「荐」** → `ING_BRAND` 顶部插入 `["关键词", "推荐品牌"]`

详见 `index.html` 中 `<script>` 开头的「内容扩展指南」注释。
