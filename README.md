## 两个「官方公开」的重量级配方

市面上绝大多数品牌配方属商业机密，本项目收录了公开渠道确认过的官方配比，可作为复刻锚点：

**霸王茶姬**（2024 年公开成分表）：茶汤 **66%** + 优质牛乳 **19%** + 冰勃朗基底乳 **8%** + 风味糖浆 **7%**
> 关键在基底乳只占 8%——很多人复刻失败正是猛加奶基底，变成甜腻香精味。

**茉酸奶**（国内现制酸奶领域首家公开配方）：牛油果冰沙 **58%** + 醇臻厚乳/牛乳 **19%** + 有机酸奶 **17%** + 果肉盖顶 **6%**
> 结构逻辑和奶茶相反：果肉冰沙为主、酸奶只占约 1/5。酸奶放太多，打出来是稀酸奶而非奶昔。

## 功能特性

- **十一大专区**：频道页 Tab 切换（常识科普 / 全部 / 配方分组 / 工具箱）；「全部」直接平铺当前专区所有配方，也可切回分组按品牌浏览
- **难度分级**：全部 508 条配方标注 **一星菜鸡 / 二星小厨 / 三星厨师长 / 四星大厨 / 五星中华小当家**（当前分布约 163 / 199 / 108 / 23 / 3）。首页**上方**按难易程度学配方、**下方**按美食分类选配方；难度页内部再按「做法 / 分类」二层筛选，并附每一档的避坑要点。新增配方会同时标注分类与难度，两者联动；难度星级直接显示在配方名后面，列表不展开也能先看难度
- **已做过标记**：配方详情可标记「已做过」（云端同步、所有者私有 RLS），侧边栏「已做过」入口按难易程度归类查看；各列表页（频道 / 分组 / 难度）右上角可一键切换「显示 / 隐藏已做过」，把做过的菜从列表里滤掉
- **列表排序**：频道 / 分组 / 难度 / 搜索 / 收藏 / 已做过，六个列表页顶部工具栏点「排序」弹出选项直接选（默认 / 难度低→高 / 难度高→低 / 按名称），当前项高亮，选择本地记住；同栏还有「已做过」显示开关
- **全文搜索**：配方、原料品牌、常识科普、工具表四类内容统一检索
- **配料品牌推荐**：每条配料自动关联网友口碑推荐品牌（「荐」字标注），如冰勃朗→圣吗哪、茉莉雪芽→茶半春
- **来源可信度标注**：官方公开 / 门店 SOP（网传）/ 网络复刻 / 传统方（民间食养方），四级分明
- **常识科普**：鲜牛奶与牛乳的区别、基底乳是什么、基底酒怎么选、江西锅气怎么炒、客家人的「酿」、补气该选哪种参、没有养生壶怎么煮、投料顺序谁先谁后、红枣为什么要去核……
- **通用配比工具箱**：万能奶液公式、茶汤冲泡参数表、糖浆换算表、奶盖与小料
- **云服务**（可选）：
  - 微信授权 / 手机号登录
  - 云端收藏同步
  - **个人「不好吃」黑名单 + 垃圾箱**：标记的配方只对自己隐藏，可随时从垃圾箱恢复，不影响他人
  - AI 配方问答（登录后可用）
- **每周菜单**：本周 / 下周两周菜单，按 1–2 人家庭分量配好「每天一荤一素」共 14 道菜（只选 1–3 星难度），优先当季食材（时令随周滚动），首页与侧边栏双入口，菜单里点击就地展开做法（含用料/步骤/诀窍/收藏）；每周五由定时任务自动生成并上线下一周菜单
- **制作步骤**：全部 508 条配方均带「用料 → 做法步骤 → 小诀窍」三段展示，做法步骤为有序列表（已全部补齐）
- **移动端优先**：折叠列表、抽屉导航、每页返回按钮、平滑返回栈

## 内容原则

- 轻油、轻盐、轻糖，不做油炸；每道菜谱均带减油减盐减糖的具体技巧
- 养生茶方为日常食养整理，不能代替药物与治疗；孕期、经期、服药中或慢病人群请先咨询医生
- 品牌精确配方属商业机密，本项目内容整理自公开渠道（官方公开信息、网络流传配方、网友实测复刻），仅供家庭 DIY 参考
- 原料品牌推荐为公开口碑汇总，与任何品牌无利益关联

## 内容如何扩展（配置驱动）

知识库为纯配置驱动，加内容只改 `<script>` 顶部的数据区，无需改动视图逻辑：

1. **加配方** → `DATA.push({ cat, group, name, type, tea, items, tips, level, src })`，新分组名自动出现
2. **开新分类** → `CATEGORIES` 对应项 `ready: true` + 补 `groupLabel`
3. **加科普** → `PRIMERS[分类id].push({ q, a })`
4. **加原料品牌** → `BRANDS_DATA` 对应面板 `rows.push(...)`
5. **配料自动带「荐」** → `ING_BRAND` 顶部插入 `["关键词", "推荐品牌"]`

> `level` 取值：`official` 官方公开 / `sop` 门店 SOP（网传）/ `replica` 网络复刻 / `tradition` 传统方。

详见 `index.html` 中 `<script>` 开头的「内容扩展指南」注释。
